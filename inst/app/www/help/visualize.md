This tab is used to visualize results from your input data files.  See the MassWateR <a href="https://massbays-tech.github.io/MassWateR/articles/analysis.html" target="_blank">analysis vignette</a> for detailed information on the plots and methods used to create them.

The controls on the left sidebar can be used to select the parameter, date range, sites, location group (if available in the Site Data file, allows site grouping/selection by common location), result attributes (if available in the Results Data file, allows site grouping/selection by values in the Result Attribute column), threshold type (as a line on the plot), and plot type (e.g., boxplot, barplot, etc.).  The location group and result attribute dropdowns only appear if values are available for the selected parameter and date range. Each includes a "None" option if some results have no entry, i.e., sites without a location group in the Site Data file or results without a value in the Result Attribute column. Select or deselect "None" to include or exclude these results. Sites and location groups are linked, so changing one updates the other. The result attribute options are limited to those available at the selected sites. Note that sites without a location group are not shown when the Date plot is grouped by location group, and no plot is shown if only these sites are selected. The available options will change based on the selected sub-tab on the right.  A download button can be used to download an image of the visible plot.

Four types of plots can be viewed with the right sub-tabs:

1. **Season**: View monthly results for a single parameter using boxplots or barplots.
2. **Date**: View results continuously over time for a single parameter as line plots, with the lines separated by site.
3. **Site**: View results for a single parameter using boxplots or barplots separately for each site on the x-axis.
4. **Map**: View a map of summarized results for a selected parameter at each monitoring site. Results are summarized as the mean or geometric mean based on information in the data quality objective file for accuracy.  Additional options for the map can be used to change the complexity of the water features and type of basemap.
